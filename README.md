# 🔴 Бункер — Генератор для ведущего

Генератор для настольной игры **«Бункер»** на основе AI. Помогает ведущему автоматически создавать уникальные игровые сессии: апокалипсис, бункер, досье всех игроков.

## Возможности

- 🤖 **AI-генерация** — сценарий, бункер и персонажи генерируются через Gemini 2.0 Flash (OpenRouter)
- 📋 **5 типов апокалипсиса** — ИИ-восстание, ядерная война, вирус/зомби, природная аномалия, эксперимент
- 🃏 **Карты действия и состояния** — уникальные игровые механики для каждого персонажа
- 📊 **Радар-графики** — визуальный профиль пригодности каждого выжившего
- 🎭 **Управление столом** — ведущий отмечает вскрытые характеристики в режиме реального времени
- 📸 **Сохранение карточек** — экспорт досье в PNG через html2canvas
- 🖥️ **CRT-эффект** — постапокалиптическая атмосфера

## Стек

- **Frontend**: React + Vite + TypeScript + TailwindCSS + Framer Motion
- **Backend**: Express 5 + Node.js
- **AI**: OpenRouter API (google/gemini-2.0-flash-001)
- **Монорепо**: pnpm workspaces

## Запуск

```bash
# Установить зависимости
pnpm install

# Запустить API-сервер
pnpm --filter @workspace/api-server run dev

# Запустить фронтенд
pnpm --filter @workspace/bunker run dev
```

## Переменные окружения

| Переменная | Описание |
|---|---|
